# 亚马逊运营助手 数据助手

一次安装后，日常在网页输入美国站 ASIN：读取目标商品、推导同类检索词、筛选可比竞品、读取竞品详情，再由网页直接调用你的 DeepSeek。

## 安装
1. 下载网页提供的 amazon-data-assistant.zip，解压到独立文件夹。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启开发者模式，点击“加载已解压的扩展程序”，选择 manifest.json 所在文件夹。
4. 在同一个浏览器重新打开 https://yuwannn122.github.io/amazon-ops-assistant/ 。
5. 看到“数据助手已连接”后，配置个人 DeepSeek Key 并输入 ASIN。

解压文件夹需要保留。工作台和助手不需要额外的 AI 智能体账号。当前首版只支持美国站。

## 数据与权限
- 只提取 Amazon /dp/ 商品、/s 搜索页面中的公开商品字段。
- 会短暂打开前台 Amazon 标签页，读取完成后自动关闭；这是部分 Edge/Codex 浏览器禁止扩展创建隐藏标签页时的兼容方式。
- 没有 cookies、tabs 全浏览历史权限；不提取登录信息、购物车、账号字段。
- DeepSeek Key 只由工作台直接发送到 DeepSeek，不经过扩展。
- 缓存最长 30 分钟，来源时间会保留。评论数可能聚合变体；近期购买提示是下限，不能当作精确销量。
- 遇到验证码、登录要求或标题缺失时，报告读取失败，不自动处理访问验证。
- 不修改商品页面，不向 Seller Central 发布文案或修改广告。

## 当前验证边界
公开数据接口已用 B0G77TSHLN 验证了目标详情、48 个候选和五个同规格品牌详情。扩展 DOM 解析、权限、网页通信、密钥隔离和研究流程通过自动化测试。
真正的 Chrome/Edge 扩展抓取还需安装后在你的实际网络中验收；网页测试窗口没有安装此扩展。不要将测试通过理解为所有 Amazon 页面都能读取。
